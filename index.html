About

I'm a Senior Software Engineer with 9+ years at Microsoft. I started on the open source Bot Framework SDK, building the TypeScript/JavaScript and C# libraries, samples, and docs that thousands of external developers build on. Since then I've worked on conversational AI runtimes, enterprise Microsoft 365 services, and identity and authentication for Azure Bot Service and Copilot Studio.

Today I focus on large language model (LLM) agents: Model Context Protocol (MCP) developer tooling, end-to-end evaluation for AI agents, and secure multi-tenant sign-in. I like making developers faster, whether that's an SDK API, a CI pipeline that runs in half the time, or a troubleshooting guide the whole on-call rotation uses.

I came into software through a coding bootcamp in 2016, joined Microsoft as a vendor, and grew into a senior engineer. I share that path through Pasifika @ Microsoft and talks for first-generation students getting into tech.
